Colophon

Made by mechanical means

The room on the front page is a canal house at night, with a workbench and the instruments of a physicist in it. Nobody modelled it by hand. A fleet of Claude agents wrote Python that drives Blender, Blender baked the light, and three.js shows the result in your browser. Ruud set the direction and judged the pictures; the code was checked by gates, not by reading it.

A portfolio you can walk into. It runs live in a phone browser, and the scan, the cloud chamber and the Geiger counter in it are live simulations. The habit is older: at AMOLF and Laserlab Amsterdam he wrote the software that ran the experiments.

The method is borrowed from Felix Rieseberg’s “Made by mechanical means”, in which he rebuilt his homepage, a Blender-rendered room, without writing or reading the code himself. This page is the build log of the same idea; the room itself was built in one evening.

02The loop

  1. Spike end to end first. One object, an amplifier, taken through the whole path: Python model, Blender bake, web viewer, measured in a browser. Only then a second object. The spike surfaced delivery bugs that would otherwise have hit every agent after it.
  2. The code is the scene. Blender runs headless as a Python library. Every object is one module with real-world dimensions in metres, each dimension a named constant with its source, or marked unmeasured when estimated. The same assembly feeds the reference render and the web export, so the two cannot drift apart.
  3. Gates, not reading. A single script, gates.py, exits red on any miss: file size, triangles, draw calls, console errors, phone layout, and a pixel diff between Blender’s render and the browser’s frame. An agent is done when the gates pass, not when its code looks right.
  4. The agent checks itself. Each agent drives a real Chrome with Playwright, on a desktop window and an emulated iPhone, captures the console, and looks at its own downscaled screenshots before reporting. Ruud is asked only for what a browser cannot observe: taste.
  5. Broad, then double down. Several directions from one brief, built in parallel with little guidance. Ruud picks; the next round goes deeper on what landed. Objects are built the same way: parallel agents, one file each, one Blender at a time behind a lock so the machine does not run out of memory.
  6. Outside judges. The builder never grades its own work. A depth pass asked what top practitioners measure; a red-team pass argued the strongest case against the whole site. A cold five-second test with people who know Ruud’s work is planned check: has a panel run?

The fidelity gate is the honest one. Baking stores light in textures, which is what makes the room cheap enough for a phone, but a baked texture cannot know where you stand: shine that depends on the viewing angle is lost. On the first three-object slice the error was 12.3. On the dusk room it was 2.49, and the ratchet was set there. The canal house measures 3.26, above it; layout runs report fidelity rather than fail on it, so this one is still open.

05What failed

  • The amp was a guess. The spike’s amplifier had big VU meters. Ruud’s own amplifier, the Luxman L-308, has none. The rule since: research the real object before modelling it, and put every dimension’s source next to the number.
  • The preview sandbox. The first previews went out as private claude.ai artifacts. Their sandbox refused .glb and .bin files, ignored the import map, and quietly showed the still image instead of the 3D room. Nothing errored; it just looked fine. The fix was to embed the scene in JSON, load three.js without an import map, and then stop using the sandbox for 3D at all: previews are now served from Ruud’s own machine and checked by Playwright on exactly that address.
  • The big-space detour. The agents tried four large atelier layouts, up to sixteen metres long. All four passed the size, draw-call, console and phone gates. Ruud’s verdict: “making it into a big room was a mistake”. He wanted it cozy. The gates measure whether a room works, not whether it is the right room. The modules are kept for reuse.
  • The agents’ taste lost. Of the three cozy variants the agents recommended the attic, with a reasoned case. Ruud picked none of them and named a room he had lived in. No gate could have found that.
  • Fidelity is above its ratchet. The canal house measures 3.26 against a ratchet of 2.5, mostly shine that a bake cannot carry. Three ways to close it are written down; none is built yet.
  • Some things no gate sees. 60 fps on a real phone is unmeasured: the headless number is a software rasteriser’s. The eraser’s 1.27 mm fringes are about one pixel wide at the optics viewpoint, so on most screens you see them as a change in brightness, not as stripes.
